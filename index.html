🔗 חיבור ל-Supabase

כדי לסנכרן בין כל המשתמשים, צריך לחבר את המערכת למסד הנתונים שלך.

1
היכנס ל-supabase.com ← פתח את הפרויקט שלך ← לחץ על SQL Editor והרץ:
create table yirutim (
  id uuid default gen_random_uuid() primary key,
  name text not null,
  phone text not null,
  activity text not null,
  status text default 'טרם טופל',
  note text default '',
  created_at timestamptz default now()
);
alter table yirutim enable row level security;
create policy "allow all" on yirutim for all using (true);
2
לך ל-Settings → API — העתק את Project URL ואת anon key
3
